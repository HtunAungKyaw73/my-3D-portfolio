# Favicon Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the lightning-bolt favicon with the approved "Orbit" design (dark tile + gradient sphere + white ring).

**Architecture:** Single static asset swap — overwrite `public/favicon.svg`. `index.html` already references `/favicon.svg`, so no other files change.

**Tech Stack:** Static SVG asset; verified via existing build (`tsc -b && vite build`)

## Global Constraints

- SVG must be 48×48 viewBox, dark rounded tile `#100D1A` corner radius 11
- Sphere: radial gradient `#D9C2FF` → `#863BFF` → `#4C1D95`
- Ring: `#EDE6FF`, rotated -18°
- User performs visual verification before merge

---

### Task 1: Replace favicon and verify build

**Files:**
- Modify: `public/favicon.svg`

**Interfaces:**
- Consumes: nothing from earlier tasks
- Produces: new `public/favicon.svg` served at `/favicon.svg` by Vite's public dir convention

- [ ] **Step 1: Create feature branch**

```bash
git checkout -b feat/favicon-orbit
```

- [ ] **Step 2: Overwrite public/favicon.svg**

Replace the file contents entirely with:

```svg
<svg xmlns="http://www.w3.org/2000/svg" width="48" height="48" viewBox="0 0 48 48">
  <defs>
    <radialGradient id="g" cx="35%" cy="30%" r="90%">
      <stop offset="0%" stop-color="#D9C2FF"/>
      <stop offset="55%" stop-color="#863BFF"/>
      <stop offset="100%" stop-color="#4C1D95"/>
    </radialGradient>
  </defs>
  <rect width="48" height="48" rx="11" fill="#100D1A"/>
  <circle cx="24" cy="24" r="12.5" fill="url(#g)"/>
  <ellipse cx="24" cy="24.5" rx="19" ry="6" fill="none" stroke="#EDE6FF" stroke-width="2.2" transform="rotate(-18 24 24.5)"/>
</svg>
```

- [ ] **Step 3: Verify build**

```bash
npm run build && npm run lint
```

Expected: both pass with no errors.

- [ ] **Step 4: Commit**

```bash
git add public/favicon.svg
git commit -m "feat: replace favicon with orbit design"
```

- [ ] **Step 5: Hand off for visual verification**

User verifies in browser (hard refresh or incognito to bypass favicon cache). Merge happens only after user approval.
